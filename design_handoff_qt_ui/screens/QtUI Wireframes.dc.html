4Edge-refine storyboard

Touching the real workpiece edges turns vision's approximate XY into concrete, workpiece-oriented actuals. Vision already knows the edge to a pixel, so the probe refines rather than blindly hunts. 4a storyboards it; 4b gives it the stock-dimensions UI home it doesn't have yet.

4aEdge-refine flow — approach normals → angle → radius push-out
1 · Vision's approximate edges
XY vision∠ manual
Rectangular stock; origin & angle are close but soft.
→
2 · Propose edge targets
propose_edge_targets drops points beside each edge; each probes inward along its approach normal.
→
3 · Touch & find direction
Contacts are tool-center points. Two on one edge give its true direction.
→
4 · Radius push-out → pin origin
XY edge · probe
Radius push-out happens after the angle, so it never inherits vision's angle error.

Note · only the two edges through the origin are supported (approach ≈ 0 and ≈ π/2) — far edges would need the stock size, which the frame doesn't hold.

How the workpiece frame gets refined. The frame is always complete & cuttable from cheap sources (vision XY + typed thickness); probing only raises fidelity on whatever you point it at. 3a storyboards the headline Z-mesh flow; 3b is the always-visible frame inspector that drives every strategy.

→
4 · Frame updated → warp
